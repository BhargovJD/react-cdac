Asynchronous JavaScript means:

--------------------4.Understanding JSX--------------------
What is JSX in React?
JSX stands for JavaScript XML. It is a syntax that allows you to write HTML-like code inside JavaScript. 
React uses JSX to describe what the user interface (UI) should look like.

State is data that a component remembers and can change over time.
